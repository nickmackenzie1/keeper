# Keeper backlog

Ideas for later, roughly in order of how much they'd help.

- **Shelf photo scan** — take a picture of a whole shelf (at home or at Talize / Value Village), pick out every spine, and show which ones you already own, which are upgrades, and which are worth grabbing: well rated, or related to things you own (same series, director, actors).
- **Cover photo → title** — snap the front cover instead of the barcode (OCR on the server).
- **Series awareness** — "You own Alien (1979); this is Aliens, the sequel" using TMDB collections.
- **Wishlist** — mark movies you want so they light up when scanned in a store.
- **Donate pile** — when you upgrade, suggest the old DVD for the donate box.
- **Bulk import** — paste or scan a stack fast to load the existing collection.
- **Stats** — counts by format, decade, genre; upgrade progress.
- **Loans** — "lent to …" so you know where a disc went.
